# game
A browser-based game - steer through light gates, avoid hazard blocks, and keep your combo alive!

## ScholarPilot (scholarship tool)

`scholarships/index.html` is a scholarship matcher and application copilot. Fill in your profile once, see which scholarships you qualify for and why, keep an essay bank, autofill application forms with a bookmark, and track deadlines. Everything stays in your browser. See [`scholarships/DESIGN.md`](scholarships/DESIGN.md) for the engineering design process behind it.
