# Marketplace relist package: Luxury Plumbing Surplus

Prepared Sep 24, 2026. Nothing on Facebook has been deleted or changed.

| File | What it is |
|---|---|
| `01_Claude_research_prompt.md` | Prompt to paste into a new Claude chat (with web search) about funnels: ads, Instagram, YouTube and others. |
| `02_Listing_standard.md` | What makes a Marketplace listing work, with sources and common mistakes. |
| `03_Listing_review.csv` | One row per listing: recommendation, reason, new title, price, photo order, anything to check. Opens in Excel or Sheets. |
| `listings/` | One folder per listing, grouped by what to do (below). |

## Folder groups
- **1 - Rebuild now (48):** a real product photo already exists; it's now photo 01. Delete the old listing and post the new one.
- **2 - Reshoot then rebuild (21):** the only photos are boxes or cartons. `listing.txt` has a 5-shot list. Reshoot, put your new photos first, then post. The included photos work as a stopgap.
- **3 - Keep and edit in place (6):** the cover already shows the product. Open the live listing, paste the new title and description, and match the photo order.

## Posting one listing (about 2 minutes)
1. Open the folder, e.g. `1 - Rebuild now/029 Delta Stryke faucet body ... - $245`.
2. Open `listing.txt` and read **NOTES FOR YOU** at the bottom (don't paste that part).
3. On Facebook: Marketplace → Create new listing → Item for sale.
4. Photos: select `01.jpg`, `02.jpg`, … in order. They're numbered in upload order.
5. Copy **TITLE**, **PRICE** and **DESCRIPTION** from `listing.txt`. Category: Home Improvement Supplies. Condition: New.
6. Publish, then delete the old listing (its link is in the notes).

Post 10–15 a day rather than all 75 at once. Photos are resized to 2,048 px, and the camera/location metadata has been removed.
